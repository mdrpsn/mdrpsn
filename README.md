## How I work

Most automation "goes live" the moment it stops throwing errors — which is how a
business ends up with a workflow silently dropping half its leads for three months
before anyone notices.

Every build goes through the same four gates before it touches a real inbox or a real
customer:

1. **Validate** — the logic is checked node by node, not just "does it run"
2. **Verify** — every connection is inspected, never assumed correct
3. **Test** — real data, real edge cases, before it's live
4. **Activate** — only once the first three actually pass

If a step doesn't have proof behind it, it doesn't ship.
